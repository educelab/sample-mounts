# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

3D-printable sample mounts (scroll cases, interface plates, spindles, trays) for scanner/beamline data acquisition. Most of the repo is OpenSCAD source in `OpenSCAD/`, with exported STLs committed to `Models/`. Scroll cases are generated by the Python package in `scrollcase/`, which is the only part with tests.

## Commands

Render an OpenSCAD model to STL (parameters are top-level variables, overridable with `-D`):

```bash
openscad -o out.stl -D rod_type=2 "OpenSCAD/Spindle Base.scad"
```

Scroll cases (run from `scrollcase/`; uv manages the environment):

```bash
uv run scrollcase build path/to/scroll.ply -c case.toml -o out/
uv run scrollcase defaults          # print every config option as TOML
uv run pytest                       # ~30s; builds real cases
uv run pytest tests/test_lining.py::test_scroll_slides_out_toward_split
```

The hanging-frame case is rendered through `OpenSCAD/scripts/HangingCase-Generic.sh`; set `UTILS_DIR` to the absolute path of this clone first.

Build the C++ utilities (libigl is fetched automatically; `spiral-length` only builds if GSL is found):

```bash
cmake -S utils -B build && cmake --build build
```

C++ formatting follows `.clang-format` (Google-based, 4-space indent).

## Architecture

- **Shared base geometry.** `Generic Mount Disc.scad` / `Generic Mount Disc 65mm.scad` define the standard mount base and expose its dimensions as functions (`GenericMountDisc_Diameter()`, `GenericMountDisc_Thickness()`, etc.). Interface plates and spindle bases `use <>` these, so changing a disc dimension affects every dependent model. `scrollcase/src/scrollcase/mount_disc.py` mirrors both discs for the scroll case and must be updated by hand to match. `Generic Mount Ring*` is the mating ring for the disc.
- **`cylinder_outer.scad`** is used almost everywhere instead of `cylinder()`. It scales the radius so the polygon's flats (not vertices) sit at the requested radius, which matters for press fits and clearances.
- **`use <>` semantics.** Files are pulled in with `use`, so only modules/functions are imported. Library files still call their own module at the top level (e.g. `GenericMountDisc();`) so they render standalone.
- **`scrollcase/`.** Python (build123d + meshlib) port of the former OpenSCAD scroll case generator; its mesh pipeline is adapted from ScrollPrize/villa's `scrollcase`. Mesh stage (`lining.py`): align the scroll, offset it to a cavity, split at Y=0, `FixUndercuts` toward the split, offset again for the lining wall. B-rep stage (`case.py`): shell, divider, disc, nubs, escape holes, labels, stand; `scad.py` gives OpenSCAD-style primitives (extrinsic XYZ rotation, `center=` anchoring) so it reads like the original. Halves are assembled as `(body ∪ wall) − cavity`.
- **Never load meshlib and build123d in one process.** meshlib bundles its own OpenCASCADE, and the two segfault or abort together. `pipeline.py` runs `brep_worker` in subprocesses; tests that need build123d use `conftest.run_brep`.
- **OCCT is fragile with coincident or tangent curved faces.** The shell is built by clipping the honeycomb cutter, not by unioning caps or ring bands back over the cylinder; tools overshoot faces; tangent escape holes are nudged. `lining.load_brep_export` fails on any real hole in a B-rep STL, so a new feature that leaves faces coincident shows up as a build error.
- **Variants by copy.** Size/scanner variants (e.g. `SI Interface Plate - 147mm` vs `- 200mm`, `SpindleBase-*`) are separate files or separate `-D` renders, and the resulting STLs in `Models/` are named after the parameter values. When adding a variant, export its STL to `Models/` too.
- **`utils/`.** `SpiralLength.cpp` computes Archimedean spiral length via GSL, for use with `Spiral Frame.scad`.

## Known gaps

`Fragment Trays.scad` and `Hanging Frame Case.scad` `use <Diamond Interface Plate.scad>`, which is not in the repo, so they won't render as-is.
