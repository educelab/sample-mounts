# Sample Mounts

3D-printable sample mounts (scroll cases, interface plates, spindles, and
trays) for scanner and beamline data acquisition. Source and models are on
[GitHub](https://github.com/educelab/sample-mounts).

- **Models.** Ready-to-print STLs are in
  [`Models/`](https://github.com/educelab/sample-mounts/tree/main/Models).
- **OpenSCAD.** Parametric sources for most models are in
  [`OpenSCAD/`](https://github.com/educelab/sample-mounts/tree/main/OpenSCAD).
  Parameters are top-level variables and can be overridden with `-D`:

    ```bash
    openscad -o out.stl -D rod_type=2 "OpenSCAD/Spindle Base.scad"
    ```

- **Scroll cases.** Split scroll cases fit to a scroll mesh are generated by
  the `scrollcase` Python package. Start with
  [Creating a scroll case](creating-scroll-case.md), then see the
  [config reference](scroll-case-config.md) for every option.
